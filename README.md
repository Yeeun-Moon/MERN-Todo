# MERN Todo App

A so - simple full-stack todo app built with MongoDB, Express, React, and Node.js.
first app to push on Github

## Tech Stack
- Frontend: React (Vite), Axios
- Backend: Node.js, Express
- Database: MongoDB Atlas + Mongoose

## How to Run 

### Backend
```
cd server
npm install
# Create a .env file (see .env.example)
node server.js
```

### Frontend
```
cd client
npm install
npm run dev
```

Open http://localhost:5173 to view the app.
